# Changelog

## 5.0 — Aug 17, 2026

First release published on GitHub:

- Relentless task reminders: exact repeating alarms that fire in Doze mode, 1–24 reminders per day with per-task nag intervals
- Fullscreen lock-screen takeover with flashing DO IT NOW!!! overlay, looping alarm, vibration and voice — the only way out is I DID IT!
- Foreground service + wake lock keep the alarm alive for up to 15 minutes
- Material Design theme packs (Indigo Expressive, Emerald Botanical, Sunset Terracotta, Steam Rust & Copper, Midnight Obsidian) with System / Light / Dark modes
- Reminder alarm sounds: built-in sounds or a custom local audio file / ringtone
- Voice Reminder Speech reads the task title aloud
- Test mode, permission guidance, local on-device task storage, no ads
